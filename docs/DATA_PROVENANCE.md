## Synthetic data safeguards

- **Names:** from per-nationality pools (`content/names/`) combined at random. No real person is represented.
- **Clinics:** generic names ("Primary Care Centre – Khalifa City 1"), placed 300–700 m away from clusters of OSM points. No real facility brand appears.
- **Labelling:** every FHIR resource has `meta.tag = local|synthetic "Simulated cohort"`. Every API response has `label: "Simulated cohort"`, and every screen shows the badge.
