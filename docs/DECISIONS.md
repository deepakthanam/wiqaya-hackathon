# Implementation decisions

A running log of small implementation choices (working rule 10). Architecture or scope changes are agreed first.

| # | Date | Decision | Why |
|---|---|---|---|
| D-001 | 2026-11-07 | Pin Python to 3.11 (`.python-version`, `requires-python >=3.11,<3.12`). | The brief specifies 3.11. The machine default is 3.14, which some ML wheels may not support yet. |
| D-002 | 2026-11-07 | Pin HAPI to `hapiproject/hapi:v8.12.0-2` (latest stable tag on 2026-11-07) with `postgres:16-alpine`. | Reproducible builds. The tag can be changed with `HAPI_IMAGE_TAG`. |
| D-003 | 2026-11-07 | Set HAPI `client_id_strategy: ANY`. | Lets the loader use stable client-assigned ids (`demo-001`, `p-000123`) so personas have fixed URLs. |
| D-004 | 2026-11-07 | HAPI port is bound to `127.0.0.1` locally and not published in deployment. | The brief requires HAPI to stay on the internal network only. |
| D-005 | 2026-11-07 | The `api` and `web` compose services sit behind the `app` profile until M6/M7. | `make up` stays fast and only needs the FHIR store in early milestones. |
| D-006 | 2026-11-07 | Represent CareGap/Flag in FHIR as `DetectedIssue`; the rule id@version and priority components go in extensions. | `DetectedIssue` already has patient, code, evidence and mitigation (the reviewer decision); `Basic` would need more custom structure. To be confirmed in M2. |
| D-007 | 2026-11-07 | pytest skips the `slow` and `integration` markers by default; `make test-all` runs them. | Keeps `make test` and CI fast. HAPI-dependent tests run locally. |
| D-008 | 2026-11-07 | pnpm comes from corepack (`corepack enable`) rather than a global install. | pnpm is not installed on the dev machine; corepack ships with Node. |
| D-009 | 2026-11-07 | Messages are keyed by (pathway, audience, channel, language). Templates are stored one file per language (`content/messages/templates/<lang>.yaml`), plus `matrix.yaml` (what must exist), `slots.yaml` (nominal slot lengths for length checks), `labels/` and `blocklist/`. | Translation can be reviewed per language. The validator checks completeness, declared slots, SMS segments, decline options and blocklists in one place. |
| D-010 | 2026-11-07 | SMS limits are 320 characters for Latin scripts and 140 for Arabic/Indic scripts (2 segments). Each slot is counted at a nominal maximum length. | Follows brief §5.2. Nominal slot lengths make the check independent of real names. |
| D-011 | 2026-11-07 | Bengali (`bn`) speakers receive English messages. There is no `bn` template set. | The brief lists six languages. The gap is kept visible as a language mismatch in the equity console, not hidden. |
| D-012 | 2026-11-07 | The rule DSL has five kinds: `periodic`, `schedule`, `immunisation`, `followup` and `cascade`. The evaluator is a pure function. A `SnapshotView` raises an error if a rule reads any field not in its `data_required`, and records `fields_read`. | Privacy by construction (working rule 8) and traceability. |
| D-013 | 2026-11-07 | `ADULT_T2D_SCREEN` uses a 12-month interval when the last HbA1c is 5.7–6.4% (ADA 2026, Table 2.5). | Without this, demo persona `demo-010` (HbA1c 6.1% 18 months ago) would not be overdue for screening, contrary to brief §11. |
| D-014 | 2026-11-07 | `CASCADE_FH` uses `child_min_age_years: 0` (NICE CG71 1.1.15) and walks first-degree relatives only. | The brief asks for first-degree relatives. NICE also covers second- and third-degree relatives; this is documented as a limitation. |
| D-015 | 2026-11-07 | Publisher pages that block bots (NICE, ADA, AAP) are verified through `verification_url` (Internet Archive, PubMed Central, PubMed). `verify_sources.py` reports 403 as BLOCKED, not FAIL. | Working rule 5 requires each source URL to be fetched; we record how it was verified. |
| D-016 | 2026-11-07 | Standard codes are used only where verified on tx.fhir.org on 2026-11-07. Combination vaccines, BI-RADS, M-CHAT, developmental screen, CIN2+ and advanced colorectal neoplasia use local codes. `docs/CODES.md` is generated from `codes.yaml`. | Working rule 4. |
| D-017 | 2026-11-07 | Commemoration Day (30 Nov) is listed as an observance, not a holiday. It is absent from the 2026 u.ae public-holiday list. | Verified source; avoids closing clinics on a working day. |
| D-018 | 2026-11-07 | OSM clinic points are stored without names and used only for coordinates and density. Generic clinics are placed near clusters of OSM points with a 300–700 m offset. | Working rule 7: no real facility brands. |
| D-019 | 2026-11-07 | Each generator stage (population, latent, consent, history) gets its own RNG from `SeedSequence(seed).spawn`. | Same seed gives byte-identical output, and changing one stage does not reshuffle the others. Tested in `tests/test_generator.py`. |
| D-020 | 2026-11-07 | Pre-history "legacy" screening results are generated 1–6 years before the history window. | Screening intervals of 36–60 months are longer than the 24-month history. Without older results, almost every adult would look never-screened. |
| D-021 | 2026-11-07 | Missed appointments are FHIR `Appointment` (status `noshow`). Attended visits are `Encounter` (status `finished`). Blood pressure is one LOINC 85354-9 panel with systolic and diastolic components. The clinic for a no-show is held in an extension, because R4 does not allow Appointment.participant.actor to be an Organization. | Valid R4 modelling; HAPI rejected the Organization participant. |
| D-022 | 2026-11-07 | Clinic and van IDs use hyphens (`clinic-khalifa-city-1`). | FHIR ids may not contain underscores. |
| D-023 | 2026-11-07 | Latent ground truth lives only in `data/hidden/latent_truth.parquet`. `repo.load_latent()` refuses callers outside `wiqaya.generator`, `wiqaya.simulate` and `wiqaya.evaluate`. | Brief §3.1: models and the API never see it. |
| D-024 | 2026-11-07 | People whose `clinical_data` consent is `not_asked` are excluded, as well as those with `denied`. Both counts are reported. | Privacy by default. The brief names `denied`; `not_asked` (~1%) is treated the same way. |
| D-025 | 2026-11-07 | A genomic finding counts as a cascade index reason only if the index person granted `genomic` consent. A confirmed FH diagnosis counts without it. | Privacy by construction. |
